# 考研智能题库与复习工作台 (Kaoyan Question Bank)

> 专为研究生入学考试（考研数学 · 822 控制工程基础 · 考研英语）深度定制的**高性能、沉浸式、全功能本地刷题与间隔复习工作台**。

---

## 🌟 核心设计理念与特色

- ⚡ **全键盘优先操作 (Keyboard-First)**：全套快捷键覆盖切题、评级、看解析、记笔记，实现 60 FPS 瞬时切换无卡顿。
- 📚 **多学科统一架构 (Multi-Subject Architecture)**：考研数学（高数/线代/概率论 200+ 章节全覆盖）、822 控制工程基础、考研英语全模块集成。
- 🧠 **SM-2 间隔重复复习引擎 (Spaced Repetition)**：基于遗忘曲线与记忆留存率算法，自动规划复习计划，支持自定义冲刺与会话断点续接。
- 🔗 **跨书同类题与考点工作台 (Related Questions & Topics)**：支持跨书考点归档、单列大图对比、折叠解析与多级跳转返回栈。
- 📝 **Markdown + KaTeX 专业公式笔记**：支持行内与独立 LaTeX 公式实时渲染，具备公式自适应行高与数学符号输入面板。
- 🎨 **原图高亮标注 (Canvas Marker)**：内置矢量画板，支持对题目图片与解析图进行画线、线框标记与持久化回显。
- 💾 **无损本地数据库双向同步 (Zero-Loss Storage Sync)**：实时双向联动 `localStorage` 与本地 `kaoyan_tiku_data.json`，支持历史数据全自动平滑迁移。

## 📋 模块功能一览

### 1. 多学科题库支持
| 科目代码 | 科目名称 | 涵盖教材 / 习题册 | 特色支持 |
| :---: | :---: | :--- | :--- |
| `math` | **考研数学** | 《基础30讲》《强化36讲》《1000题》《李范全书》《李范习题》《夜雨强化》《老姚高数》 | 支持 1000 题伴章合并、小题模式（F 键）、分区手风琴 |
| `822` | **控制工程基础** | 《822 教材》《小题300》《强化240》《真题分类》 | 按题型与大题分类排布，支持多问子题折叠导航 |
| `english` | **考研英语** | 历年英语真题、题型剖析与词汇库 | 独立英语工作流与分屏双语阅读器 |

### 2. 跨书同类题与考点归纳
- **考点主题库**：一键为任意题目添加/归属考点标签（如“泰勒展开与极值”、“矩阵的秩”）；
- **跨书查题浏览器**：上方 1:1 对称等宽工作台，支持书籍/学科/章节三级下拉与 5 列网格无缝跳题；
- **竖向大图流对比**：下方清晰呈现同类题目的题干原图与可折叠解析图，支持题干与解析一键放大；
- **智能跳转返回栈**：点击「跳转做此题」后**页面自动平滑置顶**，完成做题后可一键「返回原题」。

### 3. 右侧题号区智能徽章系统
题号按钮右上角配备高辨识度状态提示点，状态一目了然：
- 🟡 **亮黄圆点（`●`）**：该题包含个人笔记；
- 🔵 **亮蓝圆点（`●`）**：该题包含原图涂鸦/线框标注；
- 🟣 **霓虹粉圆点（`●`）**：该题已归入考点主题库（同类题关联）；
- 🔴 **Q / S / 书**：标记题目图片问题（Q）、解析图片问题（S）或与实书排版不符（书）。

## ⌨️ 快捷键速查表 (Keyboard Shortcuts)

### 导航与切题
| 按键 | 功能说明 |
| :--- | :--- |
| `A` / `D` 或 `←` / `→` | 切换上一题 / 下一题（小题模式下切换小题） |
| `W` / `S` | 题号网格跨行快速跳转（-5 题 / +5 题） |
| `F` | 切换父题模式 / 子题逐题模式（小题模式） |
| `Space` (空格) | 显示 / 隐藏当前题答案与详细解析 |
| `Shift + Space` | 切换“默认显示解析”偏好设置 |

### 掌握度评级（原版 5 级色板）
| 按键 | 掌握度评级 | 颜色标识 |
| :---: | :---: | :---: |
| `5` | **熟练** (Proficient) | 🟩 绿 (`#389E0D`) |
| `4` | **较熟练** (Familiar) | 🟢 黄绿 (`#7CB305`) |
| `3` | **模糊** (Vague) | 🟨 黄 (`#FBC02D`) |
| `2` | **困难** (Rusty) | 🟧 橙 (`#F57C00`) |
| `1` | **不会** (Wrong) | 🟥 红 (`#D32F2F`) |
| `0` | 清除当前评级 (未做) | ⬜ 默认灰 |

### 核心功能面板与工具
| 按键 | 功能说明 |
| :--- | :--- |
| `E` | 聚焦 / 保存当前题 Markdown 笔记 |
| `T` | 打开 / 关闭同类题与考点关联管理弹窗 |
| `R` | 打开 / 关闭 SM-2 智能复习面板 |
| `V` | 打开 / 关闭全科全局进度看板 |
| `B` | 打开 / 关闭错题本面板 |
| `Q` / `Shift + S` / `M` | 快速标记题目图异常 / 解析图异常 / 实书排版不符 |
| `Esc` | 关闭当前弹出的模态框、大图查看器或返回面板 |

## 🚀 快速上手与运行

1. **直接启动**：
   - 双击或在现代浏览器（Chrome、Edge 等）中直接打开 `index.html` 即可使用全部功能。
2. **本地 HTTP 服务（推荐）**：
   - 使用 VS Code 的 `Live Server` 扩展打开，或在终端运行：
     ```bash
     npx serve .
     # 或
     python -m http.server 8080
     ```
   - 访问 `http://localhost:8080`。

## 🔒 数据安全与自动迁移

- **本地存储安全**：所有掌握度数据、SM-2 计划、笔记与标注均由 `js/storage_sync.js` 自动持久化至本地 `kaoyan_tiku_data.json`，关闭页面或清理浏览器缓存不丢数据。
- **历史数据自动平滑迁移**：内置迁移引擎，自动识别历史版本旧字段（如历史 `shu1` 标识、历史 SM-2 格式），在启动时无缝迁移至 `math` 新规范。

## 🛠️ 技术栈

- **Core**: Vanilla JavaScript (ES6+), HTML5, CSS3 Variables
- **Math Engine**: KaTeX (LaTeX 数学公式渲染)
- **Markdown**: Marked.js + DOMPurify (安全富文本解析)
- **Canvas**: 原生 HTML5 Canvas 矢量涂鸦与高精度框选
- **Theme**: 清华紫质感调色板，支持浅色/深色主题与暗色图片智能滤镜
